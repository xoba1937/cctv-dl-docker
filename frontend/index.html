简介

央视视频下载器，支持浏览央视网节目并下载视频，基于 cctv-dl 命令行工具，Docker 一键部署。

版本

应用版本：v4.4.0

平台支持

支持 Linux x86_64 和 arm64 平台，包括 x86/arm NAS、云服务器、Intel Mac 和 Apple Silicon Mac 的 Docker。

使用说明

  1. 在「下载」页粘贴央视节目链接，点击「获取视频」
  2. 在视频列表中勾选要下载的视频（可多选）
  3. 在「下载设置」中选择清晰度、线程数和格式
  4. 点击「下载选中」提交下载任务
  5. 在「下载记录」页查看进度，完成后到保存目录取文件

修改密码

在服务器执行：docker exec -it cctv-dl-docker python3 /app/backend/cli.py password
（生成新随机密码；加 --set 新密码 可指定密码）

技术说明

核心解析、下载、解密能力来自 letr007/CCTVVideoDownloader 的 cctv-dl 工具，本项目仅做 Web 界面与 Docker 封装。

项目地址

https://github.com/xoba1937/cctv-dl-docker
